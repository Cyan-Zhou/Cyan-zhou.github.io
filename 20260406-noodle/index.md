# 如何做一碗香喷喷的卤面

清明节假期前两天去了龙南staycation，连吃了2天爆辣的江西菜，回到深圳以后，只想尝试口味清淡一些的食物。突然想到去年5月的时候做过一次卤面，那次味道有点失败，接近一年时间过去了，是时候再尝试一次。

卤面的制作过程其实并不复杂。 翻出来了去年爸妈发给我的步骤详解。

## 原料

两个人吃，其实这次买的比较多，因为同一顿饭还有一个土豆丝，一个蒸黄鱼。所以面的消耗量变少了。

牛肉--里脊肉，我觉得稍微瘦了一点，一斤，让档口老板切丝，成本48

四季豆--一斤，成本8块

细面--一斤，成本5块

## 步骤

### 原料腌制备用

牛肉腌制：牛肉用淀粉、酱油、料酒、五香粉抓匀腌制20分钟。

蒸面：在面里加入食用油搅拌，蒸10分钟左右断生。然后放凉抖散。

### 炒制

热锅冷油下牛肉。因为铁锅有段时间没用，所以把锅洗了之后烧热加了油，所以油温比较高，导致牛肉进去以后就开始粘锅。不过这个也没关系。牛肉炒到差不多的程度就加入四季豆，稍微炒制后，加入酱油、味精、盐。同时烧一锅开水，加入开水炖熟。

{{< imgbox src="https://images-1319077775.cos.ap-guangzhou.myqcloud.com/2026/04/06-16_18_04-202604061618744_926.png" width="800" title="牛肉刚下锅的样子" source="" >}}

{{< imgbox src="https://images-1319077775.cos.ap-guangzhou.myqcloud.com/2026/04/06-16_18_04-202604061618668_b2e.png" width="800" title="烧水炖煮四季豆" source="" >}}

收汁大概到这个程度（这次看其实收汁差不多刚好，稍微多或者少都可以）。盛出2/3的菜，留1/3在锅中。

{{< imgbox src="https://images-1319077775.cos.ap-guangzhou.myqcloud.com/2026/04/06-16_19_04-202604061619229_429.png" width="800" title="" source="" >}}

按照从下往上“菜-面-菜-面-菜” 把抖散的细面一半。平铺在留在锅中的肉丝豆角上，然后再将盛出的一半豆角较为均匀地撒在面上，连同汤汁。再铺最后细面，然后剩下的菜和汤汁均匀撒上

锅盖盖，小火，不同方向给锅底加热，勤换方向。一直听到锅底有轻微的嘶嘶声，说明汤汁已收干，然后关火，闷三分钟。最后在锅中把菜和面充分拌匀，即可。

{{< imgbox src="https://images-1319077775.cos.ap-guangzhou.myqcloud.com/2026/04/06-16_19_04-202604061619597_700.png" width="800" title="" source="" >}}

这一桌菜还是稍微多了一点，所以面剩下了大概4两。复盘下来，其实还是没等到嘶嘶声，并没有收干。几点下次可以注意的：

* 一开始在面上加油。没有均匀，所以最后一些没有沾到油的面就比较干
* 牛肉老了，我觉得比较像是一开始炒老了
* 四季豆其实也有点太软
